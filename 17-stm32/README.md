# Phase 17 — STM32

> **Goal:** Learn professional STM32 microcontroller development using STM32CubeIDE, HAL, and register-level programming.
>
> **Prerequisite:** Phase 5 - Microcontrollers, Phase 6 - ESP32
>
> **Outcome:** You can develop professional STM32 applications and understand the differences between ESP32 and STM32 platforms.

## What This Phase Will Cover

When complete, this phase will include:

1. **STM32 Architecture**
   - STM32 family overview
   - Cortex-M cores
   - Memory organization
   - Clock system

2. **Development Environment**
   - STM32CubeIDE
   - STM32CubeMX
   - ST-LINK debugging
   - Development workflow

3. **STM32 Peripherals**
   - GPIO
   - Timers
   - UART
   - SPI, I2C
   - ADC, DAC
   - CAN

4. **HAL and LL**
   - HAL layer
   - LL layer
   - Register-level access
   - When to use each

5. **Advanced Features**
   - DMA
   - Interrupts
   - Low power modes
   - Watchdog

6. **ESP32 vs STM32**
   - Architecture comparison
   - Use cases
   - Trade-offs
   - Selection criteria

- Phase 6 - ESP32
