# Phase 1 — Computer Fundamentals

> **Goal:** Understand how computers work at the bit level, including binary, hexadecimal, memory, CPU basics, and compilation concepts.
>
> **Prerequisite:** None
>
> **Outcome:** You can work with binary/hex, understand memory addressing, and grasp basic computer architecture.

## What This Phase Will Cover

When complete, this phase will include:

1. **Number Systems**
   - Binary
   - Decimal
   - Hexadecimal
   - Conversions between systems

2. **Data Representation**
   - Bits and bytes
   - Signed/unsigned integers
   - Two's complement
   - Character encoding

3. **Computer Architecture**
   - CPU basics
   - Registers
   - Memory (RAM, ROM, Flash)
   - Memory addressing
   - Stack vs heap

4. **Code and Data**
   - Instructions vs data
   - Compilation basics
   - Linking concepts
   - Endianness

5. **Pointer Concepts**
   - Addresses
   - Pointer basics
   - Memory layout

## Prerequisites

- Basic arithmetic skills
- Ability to follow logical instructions
