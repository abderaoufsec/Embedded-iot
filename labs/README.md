# Labs Repository

This directory contains cross-phase laboratory exercises and experiments.

## Purpose

The labs repository provides:
- Standalone lab exercises
- Cross-phase experiments
- Hardware testing procedures
- Calibration routines
- Debugging exercises

## Lab Structure

Each lab includes:
- Objective
- Required hardware
- Circuit diagrams
- Step-by-step instructions
- Expected results
- Troubleshooting guide

## Lab Categories

### Basic Electronics Labs
- LED basics
- Button inputs
- Potentiometer ADC
- PWM control

### Communication Labs
- I2C device testing
- SPI communication
- UART loopback
- CAN bus testing

### Sensor Labs
- Temperature sensor calibration
- Accelerometer testing
- Current sensor measurement
- Multi-sensor integration

### Debugging Labs
- Broken circuit diagnosis
- Protocol debugging
- Timing analysis
- Signal integrity

## Usage

Labs can be used for:
- reinforcing phase concepts
- hardware testing
- skill practice
- troubleshooting training

## Status

This repository is under development. Labs will be added as corresponding phases are completed.
