# Resource Index

Centralized directory of all learning resources referenced in this curriculum. Resources are prioritized by official documentation, free materials, and high-quality educational content.

## Resource Philosophy

This curriculum does NOT redistribute copyrighted books or course materials. Instead, we provide:
- Links to official documentation
- Links to official specifications
- Links to high-quality free resources
- References to reputable learning materials
- Local copies only when redistribution is explicitly permitted

## Local Resources

**No third-party PDFs, documentation, or images are bundled in this repository.**

The repository contains only:
- Original educational content (Markdown files)
- Cheat sheets (original quick reference guides)

All datasheets, official documentation, circuit diagrams, and external resources are accessed via links to their official sources.

## Resource Categories

### Official Documentation (Highest Priority)
- Manufacturer datasheets
- Official programming guides
- Protocol specifications
- Standard documentation

### Free Educational Resources
- University courses
- Tutorial websites
- Open-source books
- Video lectures

### Commercial Resources (Reference Only)
- Vendor-specific tools
- Commercial software
- Paid courses (linked, not included)

## Resource Quality Criteria

Resources are included based on:

1. **Official Source** - Manufacturer or standards organization
2. **Accuracy** - Technical correctness and up-to-date
3. **Clarity** - Clear explanations and examples
4. **Accessibility** - Freely available or reasonably priced
5. **Relevance** - Directly applicable to curriculum topics

## Resource Usage Guidelines

### For Learning
- Start with official documentation
- Use tutorials for practical examples
- Reference specifications for deep understanding
- Cross-reference multiple sources for complex topics

### For Projects
- Consult datasheets for component specifications
- Use official libraries when available
- Reference examples for implementation patterns
- Check manufacturer application notes

### For Debugging
- Use official troubleshooting guides
- Consult community forums
- Reference technical documentation
- Use manufacturer support resources

## Missing Resources

If you find a broken link or missing resource:

1. Check the Internet Archive for archived versions
2. Search for the resource on the official site
3. Look for alternative official sources
4. Report broken links in the repository

## Contributing Resources

When adding new resources:

1. Verify the resource is freely accessible
2. Ensure it's from an official or reputable source
3. Confirm it's relevant to curriculum topics
4. Add to this RESOURCE_INDEX.md table
5. Update relevant phase documentation
