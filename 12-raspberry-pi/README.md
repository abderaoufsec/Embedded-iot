# Phase 12 — Raspberry Pi

> **Goal:** Learn to use Raspberry Pi as an embedded/IoT gateway with GPIO, services, and IoT integration.
>
> **Prerequisite:** Phase 11 - Linux for Embedded
>
> **Outcome:** You can build Raspberry Pi-based IoT gateways with sensor integration and MQTT connectivity.

## What This Phase Will Cover

When complete, this phase will include:

1. **Raspberry Pi Setup**
   - Operating system installation
   - Initial configuration
   - SSH access
   - Headless operation

2. **GPIO Programming**
   - GPIO basics
   - Python GPIO libraries
   - C GPIO access
   - Interrupt handling

3. **Sensor Integration**
   - I2C sensors
   - SPI sensors
   - UART sensors
   - 1-Wire devices

4. **IoT Gateway Services**
   - MQTT broker setup
   - Database setup
   - Web services
   - Docker basics

5. **System Integration**
   - Service management
   - Auto-startup
   - Logging
   - Monitoring

6. **Projects**
   - MQTT gateway
   - Data logger
   - Web dashboard
   - Multi-sensor system
