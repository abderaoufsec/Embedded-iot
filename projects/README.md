# Projects Repository

This directory contains all project implementations organized by difficulty level.

## Project Structure

### Beginner Projects
Entry-level projects for learning fundamentals:
- LED blinker
- Button-controlled LED
- Traffic light simulator
- Potentiometer reader
- PWM dimmer
- Temperature reader
- UART monitor
- OLED display

### Intermediate Projects
More complex systems requiring integration:
- Environmental monitor
- Data logger
- Wi-Fi sensor node
- ESP32 HTTP server
- OLED sensor station
- Threshold alert system

### IoT Projects
Internet-connected systems:
- MQTT sensor node
- MQTT command node
- Secure MQTT node
- Raspberry Pi gateway
- Dashboard integration
- Multi-node IoT system

### Advanced Projects
Complex systems requiring multiple skills:
- FreeRTOS multi-task system
- Secure OTA system
- STM32 motor controller
- Modbus/CAN system
- Industrial edge gateway

### Capstone
Complete integrated system:
- Motor monitoring/predictive maintenance IoT system

## Project Standard

Each project should include:
```
project-name/
├── README.md           # Project documentation
├── circuit/            # Circuit documentation
│   ├── schematic.png   # Circuit schematic
│   └── wiring.md       # Wiring guide
├── src/                # Source code
├── tests/              # Test procedures
├── docs/               # Additional documentation
└── results/            # Test results and observations
```

## Project Progression

Projects are designed to be completed in order within each category, building skills progressively.

## Status

Projects are under development. Individual projects will be added as corresponding curriculum phases are completed.
