>
> **Prerequisite:** Phase 1 - Computer Fundamentals
>
> **Outcome:** You can write, compile, and debug C programs with embedded-specific considerations.

## What This Phase Will Cover

When complete, this phase will include:

1. **C Fundamentals**
   - Syntax and structure
   - Variables and types
   - Operators and expressions
   - Control flow

2. **Functions and Scope**
   - Function definition and calling
   - Parameters and return values
   - Scope and lifetime
   - Recursion

3. **Arrays and Strings**
   - Array fundamentals
   - String handling
   - Array bounds
   - Multi-dimensional arrays

4. **Pointers**
   - Pointer basics
   - Pointer arithmetic
   - Pointers and arrays
   - Function pointers

5. **Structures and Unions**
   - Struct definition
   - Struct pointers
   - Unions
   - Bit fields

6. **Memory Management**
   - Stack vs heap
   - Dynamic allocation
   - Memory leaks
   - Embedded considerations

7. **Embedded-Specific C**
   - Bit manipulation
   - Volatile keyword
   - Register access
   - Memory-mapped I/O

8. **Build System**
   - Compilation process
   - Make/CMake basics
   - Linking
   - Debugging symbols

## Prerequisites

- Phase 1 - Computer Fundamentals
- Basic algebra skills
