>
> **Prerequisite:** Phase 2 - C Programming, Phase 3 - Digital Electronics, Phase 4 - Electronics
>
> **Outcome:** You understand MCU architecture and can work with registers and memory-mapped I/O.

## What This Phase Will Cover

When complete, this phase will include:

1. **MCU Architecture**
   - CPU core vs microcontroller
   - Harvard vs von Neumann architecture
   - Memory organization
   - Bus systems

2. **Memory Map**
   - Flash, SRAM, EEPROM
   - Memory-mapped I/O
   - Address spaces
   - Memory protection

3. **Registers**
   - General-purpose registers
   - Special-purpose registers
   - Status registers
   - Register banks

4. **Clock System**
   - Clock sources
   - Clock trees
   - Clock dividers
   - Sleep modes

5. **Interrupts**
   - Interrupt concepts
   - Interrupt vectors
   - Interrupt priority
   - Context switching

6. **Peripherals Overview**
   - GPIO
   - Timers
   - UART
   - SPI, I2C
   - ADC, DAC
   - PWM

7. **Boot Process**
   - Reset sequence
   - Bootloader
   - Startup code
   - Vector table

8. **HAL and Drivers**
   - HAL concepts
   - BSP (Board Support Package)
   - Driver architecture
   - Abstraction layers
