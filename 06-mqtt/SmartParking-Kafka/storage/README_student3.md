# Student 3 — Database + Dashboard + API

## Module Overview

This module covers the **data persistence and visualization** layer of the Smart Parking IoT System.

---

## Files

```
storage/
├── database.py     ← All SQLite logic (create tables, read/write)
├── save_data.py    ← Kafka consumer that saves messages to DB
└── parking.db      ← Auto-created SQLite file

dashboard/
└── app.py          ← Streamlit live dashboard

api/
└── api.py          ← FastAPI REST API (optional)
```

---

## How to Run

### 1 — Install dependencies

```bash
pip install kafka-python streamlit fastapi uvicorn pandas
```

### 2 — Start the storage consumer (saves Kafka → SQLite)

```bash
cd storage
python save_data.py
```

### 3 — Start the dashboard

```bash
streamlit run dashboard/app.py
```

Open browser → http://localhost:8501

### 4 — (Optional) Start the API

```bash
uvicorn api.api:app --reload --port 8000
```

Open browser → http://localhost:8000/docs

## Database Tables

| Table | Description |
|---|---|
| `parking_events` | All raw sensor readings from Kafka |
| `parking_spots`  | Current status of every spot (upserted) |
| `alerts`         | All alerts generated by the consumer |

---

## Dashboard Features

- **KPI Cards** — Total / Occupied / Available / Critical alerts
- **Occupancy Bar** — Visual percentage bar
- **Zone Chart** — Bar chart per zone
- **Floor Chart** — Bar chart per floor
- **Timeline** — Line chart (last 60 min)
- **Parking Map** — Visual spot grid (green = free, red = occupied)
- **Alerts List** — Expandable alert cards
- **Events Table** — Latest sensor events

Auto-refreshes every 5 seconds (configurable in sidebar).

---

## API Endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/occupancy` | Overall occupancy |
| GET | `/occupancy/zones` | By zone |
| GET | `/occupancy/floors` | By floor |
| GET | `/spots` | All spots |
| GET | `/events` | Recent events |
| GET | `/events/timeline` | Time-series data |
| GET | `/alerts` | Recent alerts |
| GET | `/alerts/critical` | Critical alerts only |

## System Integration

```
Kafka Topics
    parking-data   ──→ save_data.py ──→ parking_events table
    parking-alerts ──→ save_data.py ──→ alerts table
                                   ──→ parking_spots table (upsert)

database.py ←── dashboard/app.py  (reads live data)
database.py ←── api/api.py        (exposes via HTTP)
```
